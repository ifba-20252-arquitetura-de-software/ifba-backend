## UML
Esquemas visuais que representam a estrutura e o comportamento do sistema.

### 1. Diagrama de Classes
> Representação das classes principais do sistema (Ex: Usuário, Assistente, Mensagem, Sessão).

### 2. Diagrama de Componentes
> Visão geral dos componentes de *hardware* e *software* e suas interfaces (Ex: Navegador, Servidor de API, Servidor de IA, Banco de Dados).

### 3. Diagrama de Sequência (Interação)
> Mostrar o fluxo de interação para uma funcionalidade chave (Ex: *Usuário envia uma pergunta > Front-end > Back-end > Core de IA > Back-end > Front-end*).
